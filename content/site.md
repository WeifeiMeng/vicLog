# Hi, I'm Vic 👋

**AI Agent Engineer / Backend Developer / Indie Hacker**

你好，我是 Vic，一名专注于 **AI Agent 与后端系统架构** 的开发者。

我热衷于探索人工智能与软件工程的交汇点，关注如何将大语言模型从简单的对话工具转变为真正具备规划、记忆、工具调用和自主执行能力的智能系统。

我的技术兴趣不仅限于模型本身，更关注模型背后的 **Runtime、Context Engineering、Agent Harness、Tool Ecosystem 以及 Infrastructure**。

我喜欢研究复杂系统的设计原理，也享受将想法从概念验证逐步构建为真实产品的过程。

## 🧠 AI & Agent Engineering

这是我目前最主要的技术探索方向。

- **Agent Architecture**：多 Agent 协作、任务规划与执行、Subagent 编排、Agent Workflow。
- **Context Engineering**：上下文管理、分层记忆、RAG、语义检索、Token Budget 优化。
- **Agent Runtime & Harness**：Agent 执行环境、沙箱隔离、工具调用、能力注册与生命周期管理。
- **Tool Ecosystem**：MCP、Skills、Plugin Architecture、A2A 通信协议。
- **LLM Infrastructure**：模型 API 集成、本地模型部署、推理服务与向量化系统。

我尤其关注如何构建**可扩展、可组合、可观测的 Agent 系统**，以及如何让多个智能体像真实的软件开发团队一样协同工作。

## ⚙️ Backend & System Engineering

后端开发是我的核心工程基础。

- **Languages**：Python、Go、Node.js / TypeScript，持续学习 Rust。
- **Frameworks**：FastAPI 及相关后端技术生态。
- **Databases**：PostgreSQL、TiDB、ClickHouse、Milvus、pgvector。
- **System Design**：分布式系统、异步任务、流式通信、API 设计、服务解耦。
- **Infrastructure**：Docker、Kubernetes、Helm、GitLab CI/CD、Nginx、Kong。

我比较关注系统的可维护性、扩展能力与运行效率，喜欢从架构设计、数据流转和执行机制等角度理解一个系统。

## ☁️ Cloud Native & AI Infrastructure

除了应用层开发，我也持续探索支撑 AI 应用运行的基础设施。

包括容器化部署、Kubernetes 服务编排、CI/CD 自动化、模型推理服务、隔离执行环境，以及数据库与存储系统的工程实践。

我认为，**一个真正可靠的 AI 产品，不仅需要聪明的模型，也需要稳定、高效且可控的工程系统。**
